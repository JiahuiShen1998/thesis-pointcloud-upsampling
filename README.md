# Master Thesis: Point Cloud Upsampling for 3D Object Detection

## Overview
This repository contains the code, scripts, experiment records, and thesis materials for my master thesis on point cloud upsampling for 3D object detection.

## Main Goals
- Build a PointRCNN baseline
- Integrate different upsampling methods
- Compare detection performance before and after upsampling
- Analyze whether classical upsampling metrics correlate with detection performance

## Planned Methods
- Baseline: PointRCNN
- EAR
- PU-Net
- PU-GCN
- Diffusion-based upsampling
- Transformer-based upsampling

## Datasets
- KITTI
- ModelNet40

## Repository Structure
- `docs/`: project notes and logs
- `paper/`: thesis-related material
- `configs/`: configs for experiments
- `scripts/`: scripts for running experiments
- `detection/`: detector-related code
- `upsampling/`: upsampling methods
- `experiments/`: per-experiment records
- `results/`: summarized results
- `data/`: data instructions only
